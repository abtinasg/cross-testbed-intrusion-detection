# Datasets: provenance, terms and preparation

**No dataset files are included in this repository**: no raw or corrected CSVs, no derived row-level arrays, no
per-flow scores and no trained model. You must obtain the data from the original providers.

## What this repository contains vs what it does not

| Category | In this repository? | Where / how |
|---|---|---|
| Research code (all stages that produced the reported results) | **Yes** (MIT licence) | `src/`, `scripts/`, `tests/` |
| Frozen configurations, schema, allow-list, policies, pre-registration | **Yes** | see `configs/README.md` |
| Aggregate experimental results (per-day/per-fold metrics, thresholds, run ledgers with hashes) | **Yes** | see `results/README.md` |
| Paper figures and tables (regenerated from the aggregate results) | **Yes** | `src/paper/` |
| CIC-IDS2017 / CSE-CIC-IDS2018 (original or corrected) | **No** | obtain from the providers below |
| Row-level derived files (score vectors `.npy`, label-free Parquet, labels, row ids) | **No** | regenerated by the pipeline; they contain IP-level row data |
| Trained final model (`RF-03_P1all.joblib`, 4.65 MB) and preprocessing artefact | **No** | derived from the data; refitted by the pipeline. SHA-256 values are recorded in `src/FASTTRACK_V23/P2_RUN/P2_SCORES_SEALED.json` |

## How to obtain the files

1. **P1.** Download https://intrusion-detection.distrinet-research.be/CNS2022/Datasets/CICIDS2017_improved.zip
   (≈ 328 MB), check its SHA-256, and extract the five day CSVs (`unzip -n`) into `P1_extracted/`.
2. **P2.** https://intrusion-detection.distrinet-research.be/CNS2022/Datasets/CSECICIDS2018_improved.zip is ≈ 9.7 GB.
   Either download it in full and extract the two members above, or fetch only those two members (≈ 2.1 GB) with HTTP
   Range requests, using the tool we used: `scripts/data_acquisition/s02_remote_zip_selective.py`. It reads the ZIP64
   central directory, downloads each member's compressed bytes, requires HTTP 206 with the exact Content-Range and
   ETag, and checks CRC32 and size while inflating:

   ```bash
   U=https://intrusion-detection.distrinet-research.be/CNS2022/Datasets/CSECICIDS2018_improved.zip
   D=~/Desktop/IDS_RAW_DATA_STAGE02A0
   mkdir -p $D/P2_download $D/P2_extracted
   python -I scripts/data_acquisition/s02_remote_zip_selective.py list  $U $D/P2_download/central_directory.json
   python -I scripts/data_acquisition/s02_remote_zip_selective.py fetch $U Wednesday-14-02-2018.csv $D/P2_download $D/P2_download/fetch.log '"26d7d2191-5f86fb8b66b7b"'
   python -I scripts/data_acquisition/s02_remote_zip_selective.py extract $D/P2_download/Wednesday-14-02-2018.csv.deflate \
       $D/P2_download/Wednesday-14-02-2018.csv.deflate.json $D/P2_extracted/Wednesday-14-02-2018.csv $D/P2_download/extract.log
   # repeat fetch + extract for Friday-16-02-2018.csv
   ```

   If the provider has changed the archive, the ETag check stops the download; the SHA-256 table below is then the
   reference for whether the content is still identical.
3. Check every extracted CSV against the SHA-256 table above. The runners refuse to read files whose hash differs.

## Preparing the experimental inputs

No separate preprocessing step is run by hand. Each fit job parses the CSVs itself with the frozen route:
91-column header check (`src/preprocessing_review/EXPECTED_CSV_HEADER_91.txt`), the 72-feature primary schema
(`src/FEATURE_SCHEMA_PRIMARY_72_DRAFT.csv`), training-range capping of infinite rate values, one-hot encoding of three
categorical fields on the training vocabulary and, for the linear models only, a signed log transform and
standardisation (`src/correction_package_C1`, `src/correction_package_C2`, `src/R5_FREEZE_F7`). Labels: a flow is
positive iff its label is not `BENIGN` and it is not marked `Attempted` (primary target); a sensitivity target removes
`Attempted` rows. For P2 the scoring job first writes a label-free Parquet copy so that labels cannot reach the scorer.
